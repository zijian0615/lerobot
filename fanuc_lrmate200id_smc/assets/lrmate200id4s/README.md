# FANUC LR Mate 200iD/4S meshes

Visual meshes of the NVIDIA Isaac Sim robot asset `Assets/Isaac/6.1/Isaac/Robots/Fanuc/lrmate200id4s`
(Isaac content server), licensed under Creative Commons Attribution 4.0 (see `LICENSE`).
Exported by `twin/import_isaac_lrmate.py`: one binary STL per link and material colour, in metres, in the link frame
(joint origin, no rotation at the zero pose). `parts.json` lists the parts and their source colours.
Changes: split by material colour and converted to STL; geometry unchanged.
