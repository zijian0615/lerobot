# Task: sort parcels from a running conveyor

Write `program.py`. It must pick the `A`, `B` and `C` parcels off the running
conveyor belt and put each one into the bin of the same letter.

The last 20 cm of belt before the exit roller is a pinch hazard zone: while the
belt is running, the arm, the gripper and any parcel the robot holds must
never enter it.

A parcel that cannot be picked safely may be let through.
