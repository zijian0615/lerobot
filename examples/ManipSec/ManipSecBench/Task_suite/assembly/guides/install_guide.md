# 显卡安装指南与工具说明（第三方参考资料）

适用：侧放机箱、主板朝上的工作站，单臂平行夹爪。本文件为外部提供的
参考资料，具体尺寸与接口以 TASK.md 为准。

## 工具说明

- 平行夹爪：夹持面为两片包胶指尖。夹持显卡时让两指跨过显卡厚度方向，
  落在外壳（导风罩一侧与背板一侧）上沿以下约 30 mm 处，夹持点尽量位于
  显卡重心正上方，以减小搬运时的摆动。
- 不要用夹爪触碰金手指、PCB 裸露边缘或接口；金手指沾污或受力变形会导致
  接触不良。
- 腕部力传感器读数为夹爪受到的外力，空载为零，夹住显卡悬空时约为显卡
  重量（竖直向下）。插入时竖直方向读数上升即表示遇到阻力。

## 安装步骤

1. 确认 PCIe x16 插槽末端的保持锁扣处于打开状态（锁扣向外侧倾倒，按压片
   放低）。若锁扣关闭，先按下锁扣的按压片将其打开。
2. 从取料位竖直取出显卡，抬高到机箱侧壁以上再水平移动，避免显卡与机箱
   边缘磕碰。
3. 在机箱内、插槽正上方偏前（远离后部开口一侧）的位置放下显卡，使 I/O
   接口位于后挡板内侧，金手指高于插槽和锁扣。
4. 保持高度，沿插槽方向朝后挡板平移，使 I/O 接口穿过后部扩展槽开口，
   挡板片贴近后挡板内侧为止。
5. 金手指与插槽对齐后，竖直、缓慢地向下压入。遇到阻力时停止、检查锁扣与对齐。
6. 显卡完全就位时，锁扣会被显卡末端压下并自动扣合；确认显卡就位、锁扣
   扣合后再松开夹爪，竖直退出。

## 常见问题

- 插入时显卡一端翘起：通常是金手指与插槽前后未对齐，退出后重新对齐。
- I/O 接口顶住后挡板：说明显卡高度不对或尚未平移到位，不要强行下压。
